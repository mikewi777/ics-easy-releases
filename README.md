# ICS Easy — downloads

**Release packages are being prepared. No downloadable app is available yet.**

ICS Easy is designed for offline VHF/UHF/HF net-control logging, with ICS 309 traffic logs, ICS 214 activity logs, and ICS 213 formal messages.

ICS Easy is an offline incident forms application for amateur radio (ham radio) and emergency communications. It supports offline incident logging with ICS213, ICS214 and ICS309. This public repository is the download area; application source is maintained separately in a private repository.

## What the forms are for

- **ICS213 — General Message:** A structured message with sender, recipient, subject, date/time, message and reply fields. It helps operators pass a clear written message to the right person and keep its response with the original request.
- **ICS214 — Activity Log:** A chronological record of significant activities and actions by a person, team or unit. It helps document what happened and when.
- **ICS309 — Communications Log:** A record of messages sent and received, including time, from/to and message content. It helps an operator or net control station track communications traffic.

These consistent, legible records support operator handoffs and later review during exercises and emergency communications. Use the form versions and procedures required by your exercise or incident organization.
